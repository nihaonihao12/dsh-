# 抖音广告过滤脚本

Tampermonkey 用户脚本：识别抖音网页版的带货广告、官方「广告」角标与自定义关键词，自动跳过。

> **本项目仅供个人学习、研究与技术交流，禁止商业使用。使用可能违反平台用户协议，风险由使用者自行评估并承担。请先阅读 [DISCLAIMER.md](DISCLAIMER.md)。**

## 功能

- **官方广告角标识别**：广告视频作者行内的 30×16 SVG 角标，结构识别，无需配置
- **购物锚点 / 商品卡片 / 购物文本**：多重 DOM 与文本判定
- **自定义屏蔽词**：命中即跳过，支持上万条
- **豁免词**：优先级最高，命中完全放行；可选「豁免不覆盖广告」
- **元素屏蔽**：右键页面元素直接生成规则，合并选择器查询
- **双击浮窗**：暂停 / 恢复过滤，不用打开面板
- **节奏可调**：跳过延迟、冷却、单步等待、扫描间隔、每分钟限流
- **配置导入导出**、诊断 JSON、可读日志（点击可跳转到对应标签页）

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey
2. 打开 `douyin-ad-skipper.user.js`（或把文件拖入浏览器），在管理器中确认安装
3. 刷新 `https://www.douyin.com/`
4. 右下角出现带绿色内发光的浮窗按钮即为安装成功

## 使用要点

- **单击浮窗** 打开 / 关闭面板
- **双击浮窗** 暂停 / 恢复过滤
- **右键元素** 可「屏蔽此标签文字 / 豁免此标签文字 / 屏蔽此元素」
- **长按浮窗 1.5 秒** 恢复默认位置、大小、透明度

完整操作说明见 [使用讲解.md](使用讲解.md)。

## 判定顺序

```
1. 豁免标签      命中 → 不跳过（最高优先级）
2. 元素规则      命中 → 跳过
3. 官方广告角标  作者行内有 30×16 SVG → 跳过
4. 购物锚点      .xgplayer-shop-anchor → 跳过
5. 可见文本      购物标记 / 商品卡片 / 屏蔽词 → 跳过
```
