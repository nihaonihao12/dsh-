# 电局发票导出

陕西省电子税务局多税号批量发票查询与导出油猴脚本。

## 简介

公司代理记账场景下，需要在陕西省电子税务局逐个切换税号，进入「全量发票查询」，按日期范围查询并导出全部发票。税号多时手工操作极其繁琐。

本脚本用 Tampermonkey 自动完成整套流程：**切户 → 主页搜索 → 查询 → 导出**，支持多税号串行处理、失败自动重跑、进度持久化与 xlsx 日志。

## 功能特性

- **多税号批量处理**：一次输入多个税号（中文逗号分隔），自动逐个切换并导出
- **自动切户**：在电局切户页自动输入税号、查询、进入、确认
- **主页搜索直达**：自动在主页搜索框输入「全量发票查询」并点击结果
- **自动查询**：自动选择查询类型（开具/取得）、填写开票日期起止，连续点击「查询」3 次
- **有票/无票判定**：依据页面出现「查询结果：合计金额」字样判定有票，无票则跳过不导出
- **失败自动重跑**：全部跑完后，若有失败项则自动重跑，直到全部成功（最多 20 轮）
- **日志 xlsx**：每处理一个税号写入一行，含状态、合计金额/税额、情况记录、失败快照、页面文字快照等
- **断点续跑**：进度持久化，页面刷新或中断后可继续
- **强制停止**：点击急停立即中止，跨标签页 1 秒内同步
- **跨页同步**：面板位置、透明度对所有页面统一
- **自动关页**：每处理完一个税号关闭多余页面，只留主页

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展（Chrome / Edge）
2. 点击下方链接安装脚本：
   - 打开 Tampermonkey 面板 → 「添加新脚本」→ 粘贴 `电局发票导出.user.js` 全部内容 → 保存
3. 首次运行时，浏览器会提示「是否允许下载多个文件」，请选择**始终允许**

## 使用前提

- 已登录陕西省电子税务局，且主页标签页保持打开（用于维持登录态）
- 账号下已授权多个税号，可在电局切户页正常切换
- 网络可访问 `cdn.jsdelivr.net`（脚本通过 CDN 加载 SheetJS 用于生成 xlsx）

## 使用步骤

1. 打开陕西省电子税务局主页：`https://etax.shaanxi.chinatax.gov.cn/loginb/`
2. 页面左上角出现第一层控制条「发票导出」，点击右侧 **⚙** 展开设置层
3. 在「运行设置」标签页填写：
   - **日期范围**：格式如 `2026.01.01-2026.12.31`
   - **税号列表**：多个税号用中文逗号分隔
   - **发票类型**：开具（销项）/ 取得（进项）
   - **日志子目录**：默认 `发票导出`
   - **查询点击间隔(毫秒)**：默认 2000
   - **关页前等待(毫秒)**：默认 3000
4. 点击 **开始**，脚本自动执行
5. 运行中可观察第一层的 `X/Y`（当前序号/总数）与当前步骤
6. 需要中断时点击第一层的红色方块或设置页的「急停」

## 控制面板说明

### 第一层（常驻小条）

- 圆角长方形，可拖动移动位置
- **未运行**：左侧绿色三角「开始」，中间「发票导出」，右侧 ⚙ 展开设置
- **运行中**：左侧红色方块「急停」，紧接着一个转动的圆环，显示 `X/Y`（当前税号序号/总数）与当前步骤
- 拖动可改变位置，位置与透明度在所有页面同步
- 透明度可在第二层「第一层格式设置」中调整

### 第二层（设置面板）

两个标签页：

**运行设置**
- 日期范围（`YYYY.MM.DD-YYYY.MM.DD`）
- 税号列表（中文逗号分隔）
- 发票类型（单选框：开具/取得）
- 日志子目录
- 查询点击间隔（毫秒）
- 关页前等待（毫秒）
- 「出错时立即停止（保留进度）」勾选项
- 开始 / 急停 / 清空进度 按钮
- 进度区：已完成数、当前税号、当前步骤、状态、失败记录数

**第一层格式设置**
- 透明度滑块（30% ~ 100%）
- 当前位置显示
- 重置位置按钮

## 工作流程

脚本按以下步骤循环处理每个税号：

1. **切户页**：输入税号 → 点击查询 → 找到该税号的行 → 点击「进入」→ 弹窗点「确定」
2. **返回主页**：切户完成后回到主页
3. **主页搜索**：在搜索框输入「全量发票查询」→ 点击下拉结果
4. **卡片页**：在发票查询统计页点击「全量发票查询」卡片
5. **查询页**：选择查询类型 → 填写开票日期起止 → 连点 3 次「查询」
6. **结果判定**：
   - 出现「查询结果：合计金额」→ **有票**，继续导出
   - 未出现且表格稳定 → **无票**，记录后跳过
7. **导出**：点击「导出」→ 点击「导出全部」，浏览器开始下载
8. **归档**：记录日志 → 推进到下一个税号 → 关闭多余页面回主页

全部税号跑完后，若有失败项，自动仅对失败税号重跑，直到全部成功或达到 20 轮上限。

## 日志说明

日志文件名为 `发票导出日志_YYYYMMDD_HHmmss.xlsx`（以点击「开始」的时间命名），保存在下载目录下的指定子目录中。

每完成一个税号会覆盖写入一次，确保中断时日志仍是最新的。

字段：

| 字段 | 说明 |
|---|---|
| 序号 | 日志行号 |
| 总户数 | 本轮税号总数 |
| 税号 | 统一社会信用代码 |
| 发票类型 | 开具 / 取得 |
| 状态 | `有票-已导出` / `无票` / `失败` / `失败-已停止` |
| 情况记录 | 如 `失败 18:22`、`成功 18:25`，记录该次处理的成功/失败与时间 |
| 合计金额 | 页面统计的合计金额（有票时） |
| 合计税额 | 页面统计的合计税额（有票时） |
| 开始时间 | 该税号处理开始时间 |
| 完成时间 | 该税号处理完成时间 |
| 耗时(秒) | 处理耗时 |
| 失败步骤 | 失败时卡在哪一步 |
| 失败URL | 失败时的页面地址 |
| 错误摘要 | 失败原因 |
| 失败时页面快照 | 失败时的页面文字（该税号最终成功后会被清空） |
| 页面文字快照 | 查询结果页面的文字内容 |

**说明**：同一税号若经历失败后重跑成功，日志中会有多行记录（一行失败 + 一行成功），「情况记录」列可看到 `失败 HH:MM` 和 `成功 HH:MM`。该税号最终成功后，此前失败行的快照内容会被清空以减小体积。

## 技术说明

### 页面识别

脚本通过 URL 与 DOM 特征识别当前所处页面：

- 主页：`etax.shaanxi.chinatax.gov.cn/loginb`
- 切户页：`tpass.shaanxi.chinatax.gov.cn/.../identitySwitch`
- 卡片页：存在 `.g-card-menu-item__title`
- 查询页：存在 `.filter-btns` + `form.t-form` + `input[placeholder="开票日期起"]`

### 跨页面接力

由于「点击搜索会打开新标签页」「切户后会跳回主页」，脚本在每个匹配页面加载后重新读取存储的进度状态，决定自己该执行哪一步，形成接力。

关键校验：主页只有在 `switchedTaxId === 当前税号` 时才会执行搜索，避免跳过切户直接查询。

### 日期填写

页面日期控件是 TDesign DatePicker，输入框为只读。脚本模拟真实键入并在输入框内按 Enter 确认，最多重试 3 次，每次校验值是否被页面回填覆盖。

### 有票判定

不依赖金额数值，而是检测 `.statistics-infobox` 内是否出现「查询结果：合计金额」字样——这是页面在有结果时才会渲染的文案。

无票时该字样不出现，脚本通过「表格区域渲染完成且连续 1.5 秒无变化」判定为无票，最多等待 20 秒。

### 下载检测

不拦截、不改名，仅监听 `<a download>` 点击等下载触发信号，用于确认导出已发起。

## 已知限制

- 下载的文件由浏览器原生命名，脚本不重命名；如需按税号整理，请自行批处理
- 新标签页中 Tampermonkey 的 `GM_*` API 可能不可用（由页面 `window.open` 打开的标签页），脚本已做兼容处理
- 页面若发生较大改版，部分选择器可能失效，届时需更新脚本
- 依赖 jsdelivr CDN 加载 SheetJS，若网络不通需自行改为本地引入
