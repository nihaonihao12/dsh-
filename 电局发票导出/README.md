# 电局发票导出

陕西省电子税务局多税号批量发票查询与导出油猴脚本。

## 简介

公司代理记账场景下，需要在陕西省电子税务局逐个切换税号，进入「全量发票查询」，按日期范围查询并导出全部发票。税号多时手工操作极其繁琐。

本脚本用 Tampermonkey 自动完成整套流程：**切户 → 主页搜索 → 查询 → 导出**，支持多税号串行处理、失败自动重跑、进度持久化与 xlsx 日志。

## 功能特性

- **多税号批量处理**：支持从 Excel 整列直接粘贴（每行一个），也可用中文逗号分隔，自动去重、自动转大写、自动丢弃公司名等非税号内容
- **自动切户**：在电局切户页自动输入税号、查询、进入、确认
- **主页搜索直达**：自动在主页搜索框输入「全量发票查询」并点击结果
- **自动查询**：自动选择查询类型（开具/取得）、填写开票日期起止，连续点击「查询」3 次
- **有票/无票判定**：依据页面出现「查询结果：合计金额」字样判定有票，无票则跳过不导出
- **无权限自动识别**：切户页点查询后清空输入框，结果表里仍未出现该税号即判为「无权限」，记录后永久跳过，后续轮次不再空转
- **失败自动重跑**：全部跑完后，若有失败项则自动重跑，直到全部成功（最多 20 轮）
- **日志 xlsx**：多轮时「汇总」工作表排第一（按税号去重，每户只留最终结果，首行带一行汇总报告），其后是「第一轮」「第二轮」…各轮明细；含状态、合计金额/税额、情况记录、失败快照、页面文字快照等
- **txt 运行日志**：与 xlsx 同目录、同下载时机，记录带时间戳的运行轨迹，排查脚本问题用
- **金额自动提取**：从页面文字快照中提取「合计金额 / 合计税额」，以会计专用格式写入；成功但无该文案时记 0
- **断点续跑**：进度持久化，页面刷新或中断后可继续
- **强制停止**：点击急停立即中止，跨标签页 1 秒内同步
- **跨页同步**：面板位置、透明度对所有页面统一
- **自动关页**：每处理完一个税号关闭多余页面，只留主页

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展（Chrome / Edge）
2. 点击下方链接安装脚本：
   - 打开 Tampermonkey 面板 → 「添加新脚本」→ 粘贴 `电局发票导出.user.js` 全部内容 → 保存
3. 首次运行时，浏览器会提示「是否允许下载多个文件」，请选择**始终允许**

## 使用前提

- 已登录陕西省电子税务局，且主页标签页保持打开（用于维持登录态）
- 账号下已授权多个税号，可在电局切户页正常切换
- 网络可访问 `cdn.jsdelivr.net`（脚本通过 CDN 加载 SheetJS 用于生成 xlsx）

## 使用步骤

1. 打开陕西省电子税务局主页：`https://etax.shaanxi.chinatax.gov.cn/loginb/`
2. 页面左上角出现第一层控制条「发票导出」，点击右侧 **⚙** 展开设置层
3. 在「运行设置」标签页填写：
   - **日期范围**：格式如 `2026.01.01-2026.12.31`；右侧「今年」按钮可一键填入「今年 1 月 1 日 - 今天」
   - **税号列表**：可从 Excel 整列直接粘贴（每行一个），也可用中文逗号分隔；会自动去重、转大写、丢弃公司名等非税号内容，只保留 15–20 位字母数字
   - **发票类型**：开具（销项）/ 取得（进项）
   - **查询点击间隔(毫秒)**：默认 2000
   - **关页前等待(毫秒)**：默认 3000
4. 点击 **开始**，脚本自动执行
5. 运行中可观察第一层的 `X/Y`（当前序号/总数）与当前步骤
6. 需要中断时点击第一层的红色方块或设置页的「急停」

## 控制面板说明

### 第一层（常驻小条）

- 圆角长方形，可拖动移动位置
- **未运行**：左侧绿色三角「开始」，中间「发票导出」，右侧 ⚙ 展开设置
- **运行中**：左侧红色方块「急停」，紧接着一个转动的圆环，显示 `X/Y`（当前税号序号/总数）与当前步骤
- 拖动可改变位置，位置与透明度在所有页面同步
- 透明度可在第二层「第一层格式设置」中调整

### 第二层（设置面板）

两个标签页：

**运行设置**
- 日期范围（`YYYY.MM.DD-YYYY.MM.DD`，右侧「今年」按钮一键填入今年 1 月 1 日到今天）
- 税号列表（中文逗号分隔）
- 发票类型（单选框：开具/取得）
- 查询点击间隔（毫秒）
- 关页前等待（毫秒）
- 「出错时立即停止（保留进度）」勾选项
- 开始 / 急停 / 清空进度 / 保存日志 按钮（保存时同时产出 xlsx 与 txt 两份）
- 进度区：本轮完成数、成功户数、当前税号、当前步骤、状态、日志工作表、无权限跳过数、失败记录数

**第一层格式设置**
- 透明度滑块（30% ~ 100%）
- 当前位置显示
- 重置位置按钮

## 工作流程

脚本按以下步骤循环处理每个税号：

1. **切户页**：输入税号 → 点击查询 → 等待结果刷新 → 清空输入框 → 在结果表中查找该税号
   - 找到 → 点击「进入」→ 弹窗点「确定」
   - 找不到 → 记「无权限」，加入跳过名单，直接处理下一个税号
   - 若「确定」弹窗迟迟不出现，脚本会回主页核对是否已切成目标税号：已切换则视为成功继续，仍停在切户页才判失败
2. **返回主页**：切户完成后回到主页
3. **主页搜索**：在搜索框输入「全量发票查询」→ 点击下拉结果
4. **卡片页**：在发票查询统计页点击「全量发票查询」卡片
5. **查询页**：选择查询类型 → 填写开票日期起止 → 连点 3 次「查询」
6. **结果判定**：
   - 出现「查询结果：合计金额」→ **有票**，继续导出
   - 未出现且表格稳定 → **无票**，记录后跳过
7. **导出**：点击「导出」→ 点击「导出全部」，浏览器开始下载
8. **归档**：记录日志 → 推进到下一个税号 → 关闭多余页面回主页

全部税号跑完后，若有失败项，自动仅对失败税号重跑，直到全部成功或达到 20 轮上限。**判为「无权限」的税号不计入失败项，不会被重跑。**

## 日志说明

每次保存日志会**同时生成两份文件**，都直接保存在浏览器默认下载目录（通常是 `D:\Downloads`），不分子目录：

| 文件 | 内容 |
|---|---|
| `发票导出日志_YYYYMMDD_HHmmss.xlsx` | 结构化结果表（每户一行，多轮时「汇总」排第一） |
| `脚本运行日志_YYYYMMDD_HHmmss.txt` | 纯文本运行轨迹，用于排查脚本问题 |

文件名里的时间以点击「开始」的时间为准，两份文件时间戳一致、互相对应。

**下载时机**：只在轮次全部结束、任务完成、点击急停、或手动点「保存日志」时才下载，避免中途反复下载同名文件而生成一堆 `(N)` 副本。

**防重复下载**（3.5.1 起）：同一份日志（同一文件名 + 同样行数 + 同样轮次）在 20 秒内只会下载一次；30 秒内重复点击急停也只会执行一次。多标签页同时开着面板时，其他页面不会各自再下载一份。

**关于保存位置**（3.6.1 起）：两份文件都由脚本直接写到默认下载目录，不再分子目录。这样 `.xlsx`（浏览器判定为危险类型 `danger_type=4`、会忽略子目录）和 `.txt` 都会落在同一个地方，不会再出现「一个在 `D:\Downloads`、一个在 `D:\Downloads\发票导出`」的错位。若系统开启了「下载前询问保存位置」，浏览器仍会弹框让你选，那属于浏览器设置。

**txt 运行日志内容**：文件开头是汇总头（导出时间、对应的 xlsx 文件名、日期范围、发票类型、税号数、日志行数、轮次），随后是按时间顺序记录的事件，每行形如：

```
2026-11-23 11:27:45 [切户] 已填入税号 91610125MA6TYQEK3R
2026-11-23 11:27:52 [查询页] 查询类型已设为「开具发票」
2026-11-23 11:28:03 [查询结果] 91610125MA6TYQEK3R 有票：合计金额=176,640.40 合计税额=2,659.60
2026-11-23 11:28:09 [下载] 检测到下载触发：a[download] click
```

事件标签包括：`开始`（启动参数）、`页面`（每次页面加载的完整 URL）、`步骤`（页面/步骤/税号/轮次的状态轨迹）、`切户`、`无权限`、`主页`、`卡片页`、`查询页`、`查询结果`、`导出`、`下载`、`完成`、`跳过`、`失败`、`轮次`、`停止`、`异常`（含异常信息与堆栈前几行）。

txt 最多保留最近 4000 行，超出时自动丢弃最早的行。

**多工作表与汇总**：日志按轮次分表——只跑一轮时为单个「导出日志」工作表；跑多轮时为「第一轮」「第二轮」…，外加一个汇总全部记录的「汇总」表，且**「汇总」排在第一个**。

**汇总表去重**：`汇总` 按税号只保留一条**最终结果**（同一税号多轮记录中，以最后一次出现的为准）。例如 130 户跑了 21 轮、共产生 210 行明细，`汇总` 里仍然是 130 行：成功 129（有票 82 + 无票 47）、失败 1。

**汇总报告行**：`汇总` 与单轮的「导出日志」在表头**上一行**（第 1 行，合并 A1:AF1）写一行文字报告，格式为：

```
成功 129/130　有票 82　无票 47　失败 1　无权限 0
```

其中「成功」= 有票 + 无票；无权限单独列第 5 项，不计入成功也不计入失败。各轮明细表不加这一行（表头直接从第 1 行开始）。

**进度显示**：第一层控制条运行中并排显示两组数字——`成功 X/Y`（绿色加粗，X = 已成功户数，Y = 任务总户数）和 `本轮 A/B`（A = 本轮已处理，B = 本轮总数）。第二层面板顶部同样分两行显示「本轮完成」与「成功」，并额外列出累计的有票/无票/失败/无权限条数。

**列宽与空列**：`失败URL`、`错误摘要`、`失败时页面快照`、`页面文字快照` 四列列宽统一设为 14.4 磅；为避免长文本溢出影响阅读，每列之后都插入一列空格列（共 32 列）用于截断。

字段：

| 字段 | 说明 |
|---|---|
| 序号 | 日志行号 |
| 本轮户数 | 该行所属轮次的批次户数（第一轮 130、第二轮 38…） |
| 税号 | 统一社会信用代码 |
| 发票类型 | 开具 / 取得 |
| 状态 | `有票-已导出` / `无票` / `无权限` / `失败` / `失败-已停止` |
| 情况记录 | 如 `失败 18:22`、`成功 18:25`、`无权限 18:30` |
| 合计金额 | 从页面文字快照提取的合计金额，会计专用格式 |
| 合计税额 | 从页面文字快照提取的合计税额，会计专用格式 |
| 开始时间 | 该税号处理开始时间 |
| 完成时间 | 该税号处理完成时间 |
| 耗时(秒) | 处理耗时 |
| 失败步骤 | 失败时卡在哪一步 |
| 失败URL | 失败时的页面地址 |
| 错误摘要 | 失败原因 |
| 失败时页面快照 | 失败时的页面文字（该税号最终成功后会被清空） |
| 页面文字快照 | 查询结果页面的文字内容 |

**金额规则**：脚本从「页面文字快照」里按 `合计金额：176,640.40元　合计税额：2,659.60元` 的样式提取数值写入这两列；若快照里没有该文案且本次结果为成功（`有票-已导出` / `无票`），则两列填 0；失败与被判无权限的行留空。

**说明**：同一税号若经历失败后重跑成功，**各轮明细表**里会有多行记录（一行失败 + 一行成功），「情况记录」列可看到 `失败 HH:MM` 和 `成功 HH:MM`；而 **`汇总` 表只保留这类税号的最终一条**。该税号最终成功后，此前失败行的快照内容会被清空以减小体积。

## 技术说明

### 页面识别

脚本通过 URL 与 DOM 特征识别当前所处页面：

- 主页：`etax.shaanxi.chinatax.gov.cn/loginb`
- 切户页：`tpass.shaanxi.chinatax.gov.cn/.../identitySwitch`
- 卡片页：存在 `.g-card-menu-item__title`
- 查询页：存在 `.filter-btns` + `form.t-form` + `input[placeholder="开票日期起"]`

### 跨页面接力

由于「点击搜索会打开新标签页」「切户后会跳回主页」，脚本在每个匹配页面加载后重新读取存储的进度状态，决定自己该执行哪一步，形成接力。

关键校验：主页只有在 `switchedTaxId === 当前税号` 时才会执行搜索，避免跳过切户直接查询。

### 日期填写

页面日期控件是 TDesign DatePicker，输入框为只读。脚本模拟真实键入并在输入框内按 Enter 确认，最多重试 3 次，每次校验值是否被页面回填覆盖。

### 有票判定

不依赖金额数值，而是检测 `.statistics-infobox` 内是否出现「查询结果：合计金额」字样——这是页面在有结果时才会渲染的文案。

无票时该字样不出现，脚本通过「表格区域渲染完成且连续 1.5 秒无变化」判定为无票，最多等待 20 秒。

### 下载检测

不拦截、不改名，仅监听 `<a download>` 点击等下载触发信号，用于确认导出已发起。

### 无权限判定

切户页点「查询」后等待页面刷新（按面板「查询点击间隔」），随即把输入框清空——页面已渲染的结果表不会因此消失。再在结果表里查找该税号：9 秒内仍未出现即判为「无权限」。

该判定结果写入日志（状态列 `无权限`）并加入 `noPermList`；`isTaxDone()` 把「无权限」视作已处理，因此轮次结算时不会把它算作失败项，后续轮次也不会再尝试。点「开始」并确认重新开始时该名单会被清空。

### 切户弹窗兜底

点「进入」后若 20 秒内没等到身份切换确认弹窗，脚本先判断当前是否已经离开切户页：已离开则按「切换已生效」继续（并在主页核对页面文字里是否出现目标税号）；仍停在切户页才判为失败。这样弹窗偶发不出现时不会白白丢掉整户。

### 进度口径

- `成功 X/Y`：X 是本次任务中已成功的户数（有票 + 无票，按税号去重），Y 是任务开始时输入的总户数，整轮重跑时不会累加。
- `本轮 A/B`：A 是当前这一轮已处理户数，B 是当前这一轮的批次总数，重跑后 B 会缩小到待重跑的户数。

## 已知限制

- 下载的文件由浏览器原生命名，脚本不重命名；如需按税号整理，请自行批处理
- 新标签页中 Tampermonkey 的 `GM_*` API 可能不可用（由页面 `window.open` 打开的标签页），脚本已做兼容处理
- 页面若发生较大改版，部分选择器可能失效，届时需更新脚本
- 依赖 jsdelivr CDN 加载 SheetJS，若网络不通需自行改为本地引入
- **导出文件重复**：3.5.2 已修复。旧版模拟点击时会同时派发 `click` 事件并调用 `el.click()`，导致「导出全部」被触发两次，每户生成两个内容完全相同的 `全量发票查询导出结果(N).xlsx`。修复后一次点击只发一次 `click`，并加了「10 秒内检测到下载信号就不再补点」的保护
- **个别税号反复倒在切户弹窗**：3.6.0 已加兜底（弹窗缺失时去主页核对）。若某户始终无法切换，可能是该户已注销、无代理权限或需人工确认；此时日志里该户会一直是 `失败`，可手动切一次确认原因
