# 抖音广告过滤 v5.5.0 · 使用讲解

> 这份文档讲的是「怎么用」，不是「怎么实现的」。装好之后照着做，十分钟就能摸清全部功能。
> 使用前请先读同目录的《免责声明》——本脚本仅供个人学习研究，禁止商业使用。

---

## 一、它到底做什么

三句话说完：

1. 你在抖音网页版刷推荐流时，脚本会盯着**当前正在播放的那张卡片**，看它的文字和页面结构；
2. 一旦发现是带货广告、购物卡片、直播间，或者命中你设定的关键词，就**自动切到下一条**；
3. 整个过程不联网、不下载、不改你的账号，所有配置只存在你自己电脑上。

它**不会**：下载视频、去水印、爬评论、点赞、发消息、修改任何平台数据。

---

## 二、安装

1. 浏览器先装用户脚本管理器：**Tampermonkey**（推荐）或 Violentmonkey；
2. 把 `douyin-ad-skipper.user.js` 拖进浏览器窗口，管理器会弹出安装页，点「安装」；
3. 打开或刷新 `https://www.douyin.com/`；
4. 页面右下角出现一个**带绿色内发光的方块按钮**，就装好了。

如果没看到按钮：按 F12 打开控制台，看有没有 `[广告过滤] 已加载` 这一行。没有的话检查脚本是否启用、网址是否匹配。

## 三、界面分三层

### 第一层：浮窗

就是右下角那个方块，默认 40px，带 🛒 图标。

| 外观 | 含义 |
|---|---|
| **绿色内发光** | 过滤正在运行 |
| **灰色、变暗** | 已暂停，什么都不做 |

| 操作 | 效果 |
|---|---|
| 点一下 | 展开 / 收起第二层面板（有约 260ms 延迟，用于区分双击） |
| **双击** | 暂停 / 恢复过滤，面板不打开。暂停时浮窗变灰 |
| 按住拖动 | 换位置，松手即记住 |
| 长按约 1.5 秒 | 把位置、大小、透明度一起恢复默认 |

### 第二层：功能入口列表

点开浮窗后出现的主面板，只放总开关、状态和四个功能模块的入口：

```
广告过滤  [总开关]              已跳过 45   ×
● 运行中  ↓  …364137  未检测到广告          [诊断]
───────────────────────────────────────────
屏蔽标签            85      [开关]   ›
豁免标签             4      [开关]   ›
屏蔽元素             0      [开关]   ›
广告屏蔽    官方角标 / 购物锚点  [开关]
日志                          ›
设置                          ›
```

- 每行右侧的**开关**控制该模块是否参与判定，关掉后对应逻辑整块跳过；
- 点一行的**其他位置**进入对应的三级层页面；
- 「广告屏蔽」是内置判定，没有配置页，只有开关；
- 头部的胶囊开关是**总开关**，关掉后四个模块全部停止工作。

**头部三样东西**

- **绿色胶囊开关**：总开关。点一下暂停，再点恢复。
- **已跳过 N**：本次会话累计跳过的条数，刷新页面清零。
- **诊断按钮**：把当前页面状态复制成 JSON，排障时用（后面细讲）。

**状态条**（头部下面那一行）

| 位置 | 含义 |
|---|---|
| 圆点 + 运行中/已暂停 | 当前是否在工作 |
| `↓` 或 `↑` | 脚本认为你正在往下还是往上浏览，决定跳过方向 |
| `…364137` | 当前视频的作品号后六位 |
| 最后一段文字 | 最近一次判定结果，最重要的排障信息 |

### 第三层：独立子窗口

点击二级层的入口后，会在主面板旁边弹出**独立的小窗口**，主面板保持打开、不受影响。

**子窗口操作**

| 操作 | 效果 |
|---|---|
| 按住标题栏左侧 `⠿` 拖动 | 移动窗口，松手记住位置 |
| 双击 `⠿` | 清除记忆，恢复自动吸附到主面板侧边 |
| 拖动右下角斜纹手柄 | 调整窗口宽高，松手记住 |
| 点右上角 `×` | 关闭窗口 |

默认宽 340px，最高 78% 屏高，内容超出时窗口内滚动。没手动拖过时窗口**自动吸附**在主面板右侧（放不下换左侧）；一旦手动拖过，就固定在你放的位置，不再自动吸附。

| 页面 | 内容 |
|---|---|
| 屏蔽标签 | 关键词的添加、搜索、删除 |
| 豁免标签 | 豁免词的添加、搜索、删除 |
| 屏蔽元素 | 元素规则列表与删除 |
| 广告屏蔽 | 内置判定逐项开关 + 广告文字列表 |
| 日志 | 诊断日志 / 可读日志、复制、清空 |
| 设置 | 外观、节奏参数、导入导出 |

**面板大小可调**：右下角有个小斜纹手柄，拖它改宽高，松手记住。

## 四、三级层的六个页面

### 1. 屏蔽标签（红色）

这里放**你要跳过的关键词**。

```
[输入关键词，回车添加]      [添加]
[搜索已添加的屏蔽词…]
已添加 85 / 500（新词在最前）
[原神×] [健身×] [直播间×] ...
```

- 命中任一关键词 → 这条视频跳过；
- 输入后按回车或点「添加」，**新词会插到最前面**，所以永远看得见；
- 每个标签右侧 `×` 删除；
- 搜索框只过滤显示，不影响实际生效的关键词；
- 计数 `85 / 500` 里，500 是你在设置里配的上限。

**加什么样的词才有效**

| 类型 | 例子 | 效果 |
|---|---|---|
| 长词、专有名词 | `叶黄素滴眼液`、`@某某博主` | 精准，误伤极少 |
| 通用短词 | `购物`、`健身`、`游戏` | 命中率高，但可能误伤正常视频 |
| 话题标签 | `#利己主义` 里只填 `利己主义` | 有效，`#` 不必加 |

短词加多了误判会累积（每个词独立命中），建议控制在 30–80 个。

### 2. 豁免标签（绿色）

**优先级最高的一层**。只要当前视频的文字里出现任一豁免词，脚本**立刻什么都不做**——不管它同时命中了多少屏蔽词、是不是购物锚点、有没有元素规则。

典型用法：

- 你爱看的某个博主，名字里带「游戏」被你屏蔽了 → 把他的名字加进豁免；
- 想屏蔽大部分带货，但某个产品你想看 → 把产品名加进豁免。

### 3. 元素屏蔽

比关键词更精准的一层：直接记住**某个页面元素的特征**，只要它出现就跳过。

**用法**

1. 先确保设置里「右键选取元素」是开着的（默认开）；
2. 在页面上**右键**你想屏蔽的东西，会弹出菜单：

```
屏蔽 / 豁免
├─ 屏蔽此标签文字      ← 把它的文字加进屏蔽标签
├─ 豁免此标签文字      ← 把它的文字加进豁免标签
├─ 屏蔽此元素          ← 记住这个元素的结构
└─ 取消
```

3. 选「屏蔽此元素」后，规则会出现在本页列表里。

**脚本怎么记这个元素**

按可靠性依次尝试：

| 依据 | 例子 | 稳定性 |
|---|---|---|
| `data-e2e` 属性 | `[data-e2e="video-desc"]` | 最稳 |
| 有意义的 class | `div.xgplayer-shop-anchor` | 稳 |
| 纯文本内容 | `文本: 购物 \| 视频同款` | 一般，文案变就失效 |

所以**右键时尽量点大一点的容器**（比如整个商品卡），而不是里面的一行字——容器更容易找到稳定的 class 或属性。

> 什么时候用元素而不是关键词？商品卡这种结构固定、但产品名每次都变的广告，元素规则一次就够，不占关键词额度。

### 4. 广告屏蔽

分两块：**内置判定**（脚本自己的识别逻辑）和**广告文字**（你自己加的规则）。

```
内置判定
├─ 官方广告角标   作者行 30×16 SVG        [开关]
├─ 购物锚点       播放器购物链接           [开关]
├─ 购物文本       「购物 | …」样式         [开关]
├─ 视频同款       含「视频同款」字样        [开关]
└─ 商品卡片       查看详情 / 立即购买       [开关]

广告文字
[启用广告文字]  [开关]
[输入广告文字，回车添加]      [添加]
[搜索已添加的广告文字…]
已添加 3 / 60（新词在最前）
[某产品名×] [某广告语×]
```

**内置判定**是脚本原有的广告识别能力，现在拆成五项，可以单独关。

- 全部打开时就是旧版行为；
- 如果某一项总是误判（比如「购物文本」误伤正常视频），把它单独关掉即可，不影响其他项；
- 二级层「广告屏蔽」的总开关关掉时，这五项和广告文字**全部**失效。

**广告文字** = 你自己写的广告特征词。

- 用法和「屏蔽标签」完全一样：输入、搜索、删除、命中即跳；
- **优先级不同**：广告文字按广告处理，配合「豁免不覆盖广告」开关时，可以压过豁免词；
- 典型用途：某个广告话术固定出现（比如「家人们」「限时秒杀」），但又不该把它加进普通屏蔽词（怕误伤正常视频）——放进广告文字更合适。

### 5. 日志

排障核心。分成两个子视图：

**诊断日志**——技术细节，给开发者看：

```
23:44:01  尝试跳过 7710953928041400970 | 标签：原神 | 方向: 向下 | 第 1 轮
23:44:01  方式未生效: 翻页按钮 向下
23:44:03  跳过成功 | 累计: 1 | index: 1→2 | 方向: 向下
```

**可读日志**——只记跳过结果，给你自己看：

```
23:22  跳过    标签：直播间  →  7710557481965030692
23:22  豁免    豁免：@ℒ花城  →  7710953928041400970
23:22  未跳过  广告：购物锚点  →  7708047199641408379
```

- 时间用 **hh:mm 24 小时制**；
- **点一下某条记录**，会自动跳到对应的标签页（屏蔽词 → 屏蔽标签页，豁免 → 豁免页，元素 → 元素页），方便你删掉误伤的词；
- 顶部「复制当前视图」把日志复制出来，排障时直接粘贴发人。

### 6. 设置

分几组：

**外观**

| 项目 | 默认 | 建议 | 说明 |
|---|---|---|---|
| 浮窗大小 | 40px | 36–64 | 范围 8–200 |
| 透明度 | 96% | 20–100 | 最低 1；**设到 1 几乎看不见**，且很难再点到它 |

**行为开关**

| 开关 | 默认 | 作用 |
|---|---|---|
| 方向反转 | 关 | 跳过方向反了就打开（正常不需要） |
| 失败后放弃 | 开 | 同一条试 3 轮后放弃；关掉则一直重试 |
| 右键选取元素 | 开 | 关掉后恢复浏览器原生右键菜单 |
| 扫描全页面 | 开 | 开：扫描整个可见区域；关：只扫当前卡片 |
| 右侧互动栏豁免 | 开 | 全页扫描时不算右侧点赞/评论那一竖排文字 |
| 跳过提示 | 开 | 每次跳过弹一个小提示说明原因 |
| 豁免不覆盖广告 | 关 | 开：命中豁免词时，只要页面存在明确的购物锚点/商品卡片，仍然跳过 |

**节奏参数**（决定快慢，重点看下一节）

| 项目 | 默认 | 建议 |
|---|---|---|
| 跳过延迟 | 200ms | 100–300 |
| 冷却时长 | 500ms | 200–800 |
| 单步等待 | 700ms | 400–1000（最低 50） |
| 扫描间隔 | 500ms | 250–800（最低 50） |

**数量上限**

| 项目 | 默认 | 范围 |
|---|---|---|
| 屏蔽词上限 | 60 | 1–100 万 |
| 豁免词上限 | 60 | 1–100 万 |
| 每分钟上限 | 40 次 | 1–1 万 |

**数据**

- **导出配置**：把关键词、豁免词、元素规则、全部开关和参数打包成 JSON，同时复制到剪贴板并下载文件；
- **导入配置**：粘贴 JSON 后点导入，换电脑时用；
- **恢复默认**：位置、大小、透明度、节奏参数一起重置（**不会**删除关键词和元素规则）。

## 五、它是怎么判定的（理解为什么跳了/没跳）

脚本对当前卡片按以下顺序判断，**命中即停**：

```
1. 豁免标签      命中 → 什么都不做（最高优先级）
2. 元素规则      命中 → 跳过
3. 广告屏蔽      内置判定（逐项可关）：
                  官方广告角标 / 购物锚点 / 购物文本 / 视频同款 / 商品卡片
                 + 广告文字（输入的词，命中按广告处理）
4. 关键词        命中 → 跳过
```

内置判定的每一项都能在「广告屏蔽」页单独关掉。若在设置里开启「**豁免不覆盖广告**」，第 1 步会先让位给第 3 步：命中豁免词时，只要命中任一广告判定或广告文字，仍然会跳过。这条开关适合「想放过某类内容的普通视频，但不放过它的带货广告」的场景。

**广告文字和屏蔽标签的区别**：功能一样（添加、搜索、删除、命中即跳），但**优先级不同**——广告文字按广告处理，开启「豁免不覆盖广告」时能压过豁免词；屏蔽标签则会被豁免词完全压制。

理解这个顺序能解决大部分疑惑：

- **加了屏蔽词却没跳** → 先检查是不是被豁免词拦住了（看日志有没有「豁免：xxx」）；
- **正常视频被跳了** → 看状态条显示的是「标签：xxx」还是「广告：xxx」，前者是关键词误伤，后者是内置广告识别误判；
- **直播间不跳** → 直播间文字里必须有你配的词，或者用元素规则抓直播卡片的特征。

## 六、速度怎么调

默认参数偏稳，想更快就动这两项：

| 目标 | 跳过延迟 | 冷却时长 | 单步等待 | 扫描间隔 |
|---|---|---|---|---|
| 最快（可能偶发连跳） | 0 | 100 | 400 | 250 |
| 平衡（推荐） | 100 | 250 | 500 | 300 |
| 最稳 | 200 | 500 | 700 | 500 |

**为什么「单步等待」不能一味调小**

它的作用是：点完按钮后等一会儿，看视频有没有真的切走。如果设得太短，视频还在切换动画里，脚本就误以为"没生效"，于是补发一次滚轮——**结果一次跳了两条**。

判断信号：看诊断日志里 `index: 2→4` 这种**跨了两格**的记录，就是补发了。这时候把单步等待往上加 100–200ms 即可。

**「每分钟上限」是什么**

安全阀。`已跳过` 是累计数，而每分钟上限限制的是**一分钟内的尝试次数**（默认 40）。如果判定出问题导致疯狂跳，这个值能兜住。调到 100 以上要谨慎。

## 七、遇到问题怎么查

### 第一步：看状态条

| 状态显示 | 含义 | 怎么办 |
|---|---|---|
| 未检测到广告 | 正常，没识别出内容 | 若确认该跳，检查关键词/豁免 |
| 标签：xxx | 命中你的屏蔽词 | 正常 |
| 广告：购物锚点 | 命中内置广告识别 | 正常 |
| 豁免：xxx | 被豁免词放过 | 想跳就删掉那个豁免词 |
| 冷却中 | 距离上次跳过太近 | 可调小冷却时长 |
| 触发限流 | 一分钟内跳太多 | 调高每分钟上限 |
| 这条已放弃 | 试了 3 轮没跳走 | 把「失败后放弃」关掉 |
| 等待视频加载 | 拿不到作品号 | 直播间等特殊页面，升级到 v5.5.0 已支持 |

### 第二步：点「诊断」

会把下面这些信息复制到剪贴板：

```json
{
  "version": "5.5.0",
  "enabled": true,
  "keywords": ["购物", "护眼"],
  "whitelist": ["@某个博主"],
  "runtime": { "lastResult": "未检测到广告" },
  "direction": { "effective": "down" },
  "shopAnchor": { "found": false },
  "detected": null,
  "visibleText": {
    "length": 3482,
    "sample": "共178人推荐 凭什么...",
    "keywordHit": null
  }
}
```

重点看 `visibleText`：

- `length` 很小（比如几十）→ 说明文本没收集到，可能是页面结构变了；
- `sample` 里根本没有标题 → 采集出了问题；
- `keywordHit` 有值但状态栏说没检测到 → 判定链的问题。

### 第三步：看日志

打开「日志 → 可读日志」，看最近几条是「跳过」还是「未跳过」，时间点对不对得上。

### 第四步：还不行就反馈

把这三样一起发出来，基本能定位：

1. 诊断 JSON（点「诊断」按钮复制）；
2. 可读日志最近 10 条（点「复制当前视图」）；
3. 当时页面的截图（能看到标题和右侧互动栏）。

## 八、数据与隐私

- **不联网**。脚本里没有任何 `fetch`、`XMLHttpRequest`、`sendBeacon` 调用，不会把你的数据发到任何服务器；
- **只读本页**。读的是当前页面已渲染的文字和 DOM 结构，在内存里比对，不写盘；
- **配置只在本机**。存在浏览器里（`adskip.v2.*` 这些键），可在脚本管理器里清除；
- **导出/复制是你主动触发的**。点了导出才会写剪贴板或下载文件，目标都是本机。

## 九、注意事项

1. **不要用于商业场景**。分发、打包售卖、作为付费服务的一部分都属于禁止行为，见声明第二节。
2. **不要用来源不明的修改版**。任何人都能改这个脚本，安装前建议核对发布说明里的 SHA-256。
3. **平台随时可能改版**。抖音前端一周一小改、一月一大改，脚本可能突然失效或开始误判。这不是 bug，是这类工具的常态，等更新即可。
4. **账号风险自负**。脚本通过模拟点击/滚轮切换视频，平台理论上能识别。建议用小号测试，别在主账号上长时间挂着。
5. **误跳了别慌**。看可读日志找到是哪条规则干的，点进去删掉即可，立即生效不用重启。

## 十、快速上手清单

装好之后，按这个顺序试一遍：

- [ ] 点浮窗，看到面板和「运行中」
- [ ] 刷到一条带货视频，观察它是否自动跳过，跳过时右下角是否弹出提示
- [ ] 打开「日志 → 可读日志」，确认看到了刚才那条记录
- [ ] 点一下那条记录，确认能跳回标签页
- [ ] 右键页面某个元素，试一次「屏蔽此标签文字」
- [ ] 在「设置」里把浮窗拖大一点，刷新页面看是否记住
- [ ] 点「导出配置」，确认下载了 JSON 文件

七项都通过，说明安装和基本功能都正常。
